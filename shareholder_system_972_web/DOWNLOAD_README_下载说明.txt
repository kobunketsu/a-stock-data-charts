Mac安全合并（避免Finder替换文件夹误删）
1. 先单独解压01或02，取得“安全解压合并.py”。将本次需要的972版本ZIP放进同一个下载文件夹。
2. 在终端运行（脚本路径可直接拖入终端；替换以下三个路径）：
python3 "/脚本所在目录/安全解压合并.py" --zip-dir "/存放972压缩包的目录" --output "$HOME/Downloads/股东研究系统972"
3. 脚本先检查路径、ZIP完整性和文件冲突；相同内容会跳过，不同内容绝不覆盖。可以先下部分包，以后继续合并。不要使用旧453版本ZIP。
4. 进入解压结果的 shareholder_system_972，按 README_972_ZH.md 安装分析依赖并运行 python rebuild_system.py。建议Python3.12，最低3.11；仅解压脚本可用Python3.9。

所有分包都是普通ZIP，不需要字节拼接。网页与分析根目录不同是正常设计。计算输入977项（972股票价格+股东原始合并CSV/名单/方法/日历），重算前自动逐项SHA核验。
此版972为最终有效股票池，982为日期清洗前候选。矩阵实际有完整观察窗口的股票数少于972，详见网页。没有实时抓取、自动更新、网络密钥或收益保证。
