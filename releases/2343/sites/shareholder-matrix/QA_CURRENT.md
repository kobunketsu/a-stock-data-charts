# 单列布局与两行分位数修复

## 原因与修正
两行底部跨网格第3–4行，而隐藏的样本警示仍占第4行。未指定列时，网格自动生成第二列，挤窄主数值与曲线。现在显式单列，并将直接子元素全部固定在第1列，主收益禁止换行。不通过缩小全部字体或增大高度掩盖。

## 保留行为
悬停/聚焦时高低分两行，读取竖线 h 的 p90/p10，不是显示长度L；隐藏样本不足文字，移出恢复。空值“暂无区间”。81格同高，样本/价格/研究数据不变。

## 实际浏览器验证
- 修前两列84.7px+44.8px、图宽84.7px；修后一列132.7px、图宽132.7px。
- 1180/787/590视宽（浏览器原生100/150/200%）真实截图检查：+17.73%一行，高+41.66%/低-6.79%在格内，曲线全宽。
- 五个此前N×六个L共30状态：只有一列，主值一行，曲线宽等于内容宽，所有81格同高，无文本越界。
- 页面30%/200%缩放、统计日起点/近期范围/负长值检查：高度66/440px，文字和图仍完整。
- 11340竖线分位数用例通过，显式单列回归检查通过。用户截图及内部测试截图均不包含在此公开包。
