# 来源、口径与再分发说明

本研究使用公开可访问的历史数据与用户已有的冻结快照，不代表数据供应商授予无限再分发或商业使用权。

## 数据来源
- 东方财富数据中心（https://datacenter-web.eastmoney.com/）：RPT_HOLDERNUM_DET 股东记录；公告日期字段 HOLD_NOTICE_DATE，统计截止字段 END_DATE，股东数 HOLDER_NUM。
- 东方财富 F10（同公开数据接口）：RPT_F10_EH_HOLDERNUM，使用 HOLDER_A_NUM；NOTICE_DATE 为供应商公布日期字段。A股数缺失不得以 HOLDER_TOTAL_NUM 或其他总户数字段替代。
- 新浪财经（https://finance.sina.com.cn/）：历史日行情与复权因子。以实际市场交易日对齐，不补造停牌或缺失日价格。
- 巨潮资讯（https://www.cninfo.com.cn/）：此前选定记录做原文语义抽核，例如南玻 2010 年报摘要 https://static.cninfo.com.cn/finalpage/2011-03-22/59153432.PDF 。抽核不等于逐条公告核验。

供应商日期与历史值可能修订。旧冻结输入优先保全，新恢复数据需回归审计。记录可访问的来源 URL 不构成对供应商条款的法律判断。

## GitHub 与持久化
研究代码、方法和审计摘要可另行整理为干净源码。公开仓库不应自动将第三方原始数据统一声明为原创开源许可；上传前需区分自编代码与第三方数据，并确认再分发安排。完整原始快照可先在用户私人持久空间保存。不得公开凭据、部署身份、内部协作笔记或终端日志。

## 使用边界
本系统展示历史同类事件参考，不是实时预测或保证收益；统计日起点含事后公布信息，全样本参考可能包括所选节点之后事件和该股票自身事件。按近期频率与存续名册选池仍存在选择偏差。新增观察期或价格分组不消除这些限制。
