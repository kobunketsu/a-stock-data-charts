# 972 股票池：股东人数与股价矩阵系统

本版本是最终 **972 只股票池**对应的独立矩阵系统，不是旧453版文件的混合更新。982 是原始候选数量，剔除异常日期候选后为972；采集批次名可能仍有982或529字样，以 `qualified_972.csv` 与 `POOL_METHOD.json` 为准。

矩阵为两个起点各8×8格，默认统计第20个交易日；小曲线展示0—250日，历史股价分类仍为此前60个市场交易日。红色代表相对起点累计上涨，绿色代表下跌；小样本仍着色并显示提示。默认各小图自适应纵轴，实际最大/最小值有标注；同高线不意味着相同收益幅度。

## 下载哪些文件？

- **01 网页程序**：独立静态界面与972版聚合数据，直接查看用它即可，不需要Python分析环境。
- **02 分析源码与统计结果**：本目录代码、完整精度CSV/JSON、方法、审计和发行SHA。
- **03 计算输入分包**：972股复权日行情、两份原始合并股东CSV、股票池和日期日历。重新计算时全部需要。
- **04 原始抓取证据分包（可选）**：原始行情/复权因子、股东接口页面及清单，供来源追溯，不是运行矩阵的必要重复下载。

02/03/04 都解压到同一位置，合并同名根目录 `shareholder_system_972`。每份都是普通ZIP，不是字节切片；不要把整个目录替换掉其他包已经解压的文件。不要向旧453目录覆盖。

## 安装与重算

需要Python3.11或更高，建议3.12；macOS自带旧Python3.9不适用。建议准备至少4GB可用内存和2GB空闲磁盘。查看网页无需这些计算资源。

```bash
cd shareholder_system_972
python3 -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows 改用 .venv\Scripts\activate
python -m pip install -r requirements.txt
python rebuild_system.py --check-inputs
python rebuild_system.py
```

第一条验证完整972行情、股票池、日历、主期/2019基线股东CSV以及脚本SHA，缺包或混入其他版本会停止。计算依次运行：

1. `build_event_panel.py` 调用 `clean_holders.py`，从合并原始股东记录清洗事件，结合实际复权行情构建两个起点收益路径和严格60市场交易日特征。
2. `holder_matrix_4bins/build_matrix.py` 计算双起点64格曲线、均值、中位数、分布与样本统计。
3. `holder_matrix_4bins/audit_matrix.py` 独立重构128个格子的区间、成员与计数，并核验九个收益期限。
4. 与发布版 `curves_ui.json`、`curves.json`、`daily.csv`、`event_membership.csv` 逐文件比对SHA，写入 `rebuild_result.json`。

所有计算只读冻结原始输入，覆盖派生分析结果，不联网、不自动交易、不发布网站。大型逐事件NPZ和重复事件面板未重复打包，第一步可再生。

## 能重现什么，不能声称什么？

本版入口覆盖：**已合并的原始股东CSV + 已冻结972池 + 复权行情 + 日期日历 → 记录清洗 → 事件路径 → 最新矩阵**。是否实际完整重跑通过，见同包独立验证报告与 `rebuild_result.json`；仅存在脚本不等于已完成验证。

这里的“原始股东CSV”是已将多批接口快照合并去除完全重复行的来源记录，仍由清洗脚本排除非法日期等问题；并非已准备好的旧453事件表。原始接口快照可在04证据包复核。

股票池选取和网络重新抓取不在默认重建链中。第三方接口可能改动或修订历史数据，不能保证今天重新联网下载得到相同快照。972池的形成证据、合并来源和行情来源映射应结合清单阅读。972并不代表每只股票每一期都少于30日：池条件是规定近期窗口内的平均频率等筛选，具体见 `POOL_METHOD.json`。近期选出的股票池回看历史存在选择偏差。

**本版交付的是矩阵研究系统，没有重新训练旧453版的回归预测模型，也不应把旧模型分数当作972池结果。** 不读取或扣减大盘指数收益。

## 读图口径

- 行按股东变化有符号从小到大：减少>30%、15%—30%、5%—15%、0—5%；增加0—5%、5%—15%、15%—30%、>30%。0变化单列，恰好±30%留在15%—30%。
- 列同样由小到大：下跌40%—80%、20%—40%、10%—20%、0—10%；上涨0—10%、10%—20%、20%—40%、40%—80%。普通端点左闭右开，价格恰好不变、绝对涨跌至少80%另列。
- 股东变化区间是相邻两次统计，并不等于股价固定60个市场交易日区间。
- 披露起点为数据商记载披露日期后下一个市场交易日开盘；统计起点为统计日收盘，休市用此前市场收盘，属于事后观察，当时人数通常未披露。
- 第h日是起点后第h个市场交易日收盘；披露起点的第1日不是开仓当天收盘。第0日收益归零。无交易/缺价不凭空填补。
- 收益小数乘100为百分比。每条披露事件等权，同股可重复且观察期重叠，曲线不是组合净值。
- 每格少于50记录或10股标为小样本；没有记录保留null。p10/p90是事件收益分布，不是置信区间。
- 未计费用、滑点、停牌/涨跌停成交约束；完整250日样本筛选也会产生偏差。这些统计不能证明“庄家”意图，也不保证预测效果。
